# 架构说明

## 1. 一句话

输入是**一张有向无环的数据流图** + 一个采样率；输出是**到 ADC 的噪声预算、SNR、ENOB**，以及每个观测点上的频谱/波形。

## 2. 分层

```
┌───────────────────────────────────────────────┐
│ ui/            index.html（单文件前端）         │
│                server.py（JSON API）           │
│                schema.py（参数定义，界面来源）   │
├───────────────────────────────────────────────┤
│ runner.py      一次完整运行的编排               │
├───────────────────────────────────────────────┤
│ graph.py       建图 / 校验 / 阻抗 / 分压 / 调度  │
│ metrics.py     噪声预算、SNR、ENOB              │
├───────────────────────────────────────────────┤
│ blocks/        每种块的物理行为                 │
├───────────────────────────────────────────────┤
│ spectral.py    谱表示     timedomain.py 时域工具 │
│ filterdesign.py 极点零点   netlist.py  节点法    │
└───────────────────────────────────────────────┘
```

## 3. 两套引擎

| | 解析（默认） | 时域（按需） |
|---|---|---|
| 触发 | 总是可用 | 有 `v_hi/v_lo`、启用 SR、或 `force_time` |
| 表示 | `Spectrum`：Σ Re(c_k·e^{j2πf_k t}) | numpy 数组 |
| LTI 块 | 逐频点乘 H(jω) | 线性卷积（零填充到 2n） |
| 非线性块 | 不适用 | 逐点（clamp / SR / 量化） |
| 精度 | 稳态精确 | `fs_int = OSR · fs_adc`，OSR ≤ 64 |
| 速度 | 毫秒 | 数十毫秒 |

时域路径会跑 **2 倍长度**并丢弃前半段（暖机），再按 `OSR` 抽取。指标始终从**实际采样点**重算（`_spectrum_of`），不沿用解析层的假设。

## 4. 图与阻抗

- `Graph` 负责拓扑排序、校验（无环、端口数、电流源必须接负载/TIA、至少一个 ADC）。
- **每条边的分压系数 `e.div`** 由 `zout ∥ 下游 zin` 算出，统一在 Graph 里应用，块内不再重复。
- `source_impedance()` 给噪声模型提供 `Zsrc`；`load_impedance(node)` 给电流源做 I→V。
- 多图元：`graph.adcs` / `graph.dacs` 是列表，`graph.adc` 保留为「第一个 ADC」的兼容别名。

## 5. 噪声模型

```
每块 psd(f)               输入参考 V²/Hz
  + (in·Zsrc)²            电流噪声（TIA 除外，它已输出参考）
  × |H_block→ADC(f)|²     折算到 ADC 输入
  ∫ 到 fs/2               只积到奈奎斯特
```

- 无源块额外加 `4kT·Re(Z)`（`thermal_zout`）；有源级不重复计。
- 输出参考块（TIA）用 `noise_output_referred`，不走传递函数折算。

## 6. 滤波器

两条互斥的路径，**必须给出一致的响应**：

1. **按参数**：`design_pz` 出极点/零点（Butterworth/Chebyshev/Bessel），再由 `components`/`mfb_lowpass`/`mfb_highpass` 求解元件。
2. **按元件值**：`netlist.solve` 用节点法（MNA）直接算 H(jω)，组合由 `topologies.STD` 白名单约束。

级联：设计器与 `Filter` 都按**总阶数**拆成 HP/LP 若干节，每节独立 Q 与 f0；带通 = HP 段 + LP 段。

## 7. 观测端

- `scope` / `specan` / `algo` 是 sink：只读不写，不参与传播。
- 数据来源按**连线**推导（上游 ADC/DAC），也允许手动指定。
- 每个 sink 独立保存时窗/FFT 设置，结果里按 `sink_order` 排列。

## 8. 界面

- `index.html` 单文件，内联 CSS/JS/SVG，无构建步骤。
- 右侧参数面板由 `schema.py` 的字段定义**动态生成**，所以加参数只需改 schema。
- 滤波器设计器是模态框：参数页 + 元件值页（含标准格式帮助、拓扑示意、级数翻页）。
- 图表用 canvas 手绘：频谱（对数轴 + dB）、波形（可阶梯显示，用于 DAC 的零阶保持）。
